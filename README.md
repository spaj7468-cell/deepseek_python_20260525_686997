# Шторм — Telegram-бот

Экспериментальный игровой бот на Python и aiogram: внутриигровой баланс, коллекция машин-перехватчиков, улучшения и случайные события с торнадо.

## Команды
- /start — краткая справка.
- /profil — профиль, баланс и машины.
- /shop — магазин машин.
- /storm — начать погоню, если есть доступная машина.
- /name Имя — изменить отображаемое имя.

В группах бот может выдавать игровую валюту за активность с ограничением частоты.

## Запуск
Нужен Python 3.10+ и aiogram версии 3.
Установи зависимость: python -m pip install "aiogram>=3,<4"

Задай BOT_TOKEN переменной окружения, затем запусти python deepseek_python_20260525_686997.py.

PowerShell:
$env:BOT_TOKEN="токен_из_BotFather"
python deepseek_python_20260525_686997.py

Linux/macOS:
export BOT_TOKEN="токен_из_BotFather"
python deepseek_python_20260525_686997.py

Если BOT_TOKEN не задан, программа завершится с подсказкой. Не храни токен в исходном коде.

## Данные и ограничения
- Игровые профили сохраняются в локальном файле storm_users.json в рабочей папке.
- Для постоянной работы на сервере настрой резервное копирование этого файла.
- Это прототип: перед публичным запуском нужно дополнительно протестировать одновременные обновления данных и обработку ошибок записи.
